与 App 同语义

请重点确认

  • 添加页：单链接自动识别是否清楚；“识别为单集 / 合集 / 电子书 / 播客 feed”的卡片信息是否足够。
  • 合集预览：集数、总时长、已在库、上游移除、全部处理的提示是否足够让用户判断规模。
  • Library：合集只占一张卡片、子集不混入主列表；筛选把合集当整体。
  • 合集详情：不做播放全部；单集播放/阅读、重试失败项、下载状态是否好理解。
  • 删除：“删除合集及全部单集”与“仅移除分组”两种选择是否安全、文案是否清楚。
  • Host Console：合集入口放在 Library 头部、独立 /collections 页是否符合管理习惯。

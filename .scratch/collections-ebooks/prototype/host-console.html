合集与电子书 · Host Console

Host Console 负责入库和管理：添加页统一为一个链接面板，Library 增加“合集”入口， 新增只读合集详情（状态、单集跳转、重试失败项、删除合集）。现有单集列表、筛选和搜索保持不变。

1280 × 900 现有 web 视觉 只读 + 删除/重试

添加页 · 统一链接面板

视频单集、合集、EPUB 直链、播客 feed 共用一个输入框；检测后展示预览，确认后入库。 本地路径和上传文件面板保持现状。

删除合集？

「从零开始做个人知识库」包含 12 集，其中 3 集已下载到手机。两种操作都会立即同步到 App。

Host 与 App 使用同一套两种删除语义，按钮文案写清集数；不提供“只删 Host 不删手机”的分叉。

原型说明：Host Console 为服务端渲染 + HTMX；这里的静态线框只确认信息架构与文案， 实现会复用现有 app.css、panel、chip、queue-list 的视觉语言。
